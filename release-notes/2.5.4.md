# fn-knock 2.5.4

- 系统设置中的网关配置新增「映射选择页」开关，可控制是否允许通过 `/__select__` 查看映射入口；关闭后，相关请求按未匹配路由策略处理。
- 修复退出登录后使用 Passkey 再次登录时的跳转问题，保留正确的登录目标与导航状态。
- 修复认证服务未匹配路由的处理，使网关能够对这些请求一致应用未匹配路由策略。
- 加强代理映射目标地址校验，在前后端拒绝格式错误的目标，并完善输入提示。
- 完善 DDNS 与 ACME 证书申请之间的 DNS 凭据双向复用提示，减少重复填写配置。
- 修复控制台应用入口链接的生成，正确使用公网网关配置，并应用门户的局域网导航规则。
- 完善 fnOS 证书同步失败后的批次恢复，恢复时同步核对并修复网关映射，保护共享证书索引引用，避免误清理仍被使用的证书记录。
- 更新内置 acme.sh 组件。
