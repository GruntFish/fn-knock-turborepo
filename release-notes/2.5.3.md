# fn-knock 2.5.3

- 请求日志支持按日期范围查询（最多 30 天），可按访问时间正序或倒序排列，并支持从日志中将 IP 加入黑名单，方便定位和处理异常访问。
- 优化请求日志的按 IP 聚合视图，统一时间显示，支持查看指定 IP 在所选日期范围内的请求。
- 系统设置->网关新增「禁用域名后行为」设置，可选择显示阻止页面或直接阻断连接；该设置仅影响手动禁用的子域名，不改变非允许访问时段的提示。
- 优化网页终端的输入队列、光标与画面渲染，减少连续输入时的积压和显示延迟，并共享资源轮询以减少重复请求。
- 修复运行健康监测可能停滞的问题，完善异常事件的持久化与保留，便于排查运行故障。
- Windows 版证书客户端升级至 v0.1.2，新增西部数码 DNS 验证支持。
- 加强 Windows 安装与升级的数据快照校验和回滚保护；恢复失败时保留恢复快照，降低安装异常时的数据丢失风险。
- Windows 版新增存储离线诊断命令，完善服务启动错误与安装日志；对不可重试的存储错误停止自动恢复，其他连续故障最多自动重启三次，避免无限重启。
- 完善 Windows 安装恢复、存储诊断及真实安装包的自动化发布检查。
- 修复 fnOS 证书同步时的文件权限保留问题，完善失败恢复和错误诊断，避免同步后证书无法被相关服务读取。
